# Ошхона Маркет 🍳

Мағозаи онлайн барои ҳама чиз барои ошхона — бо ҳамаи функсияҳои асосии Wildberries.
Сохташуда бо скилли **UI/UX Pro Max** (системаи дизайни «Vibrant & Block-based»:
ранги асосӣ `#059669`, акцент `#EA580C`, шрифтҳои Rubik / Nunito Sans,
мавзӯи равшанӣ ва торикӣ).

## Оғози кор

### Дар Railway (ҳостинг)

Лоиҳа барои Railway тайёр аст — ҳеҷ гуна қадаме лозим нест:

| Файл | Мақсад |
|---|---|
| `railway.json` | Билдери **NIXPACKS**, `startCommand: node server.js`, `healthcheckPath: /health` |
| `server.js` | Сервери статикии содда (Node, **бе ҳеҷ гуна зависимость**), `PORT`-ро аз муҳит мехонад |
| `package.json` | Танҳо `start: node server.js` — ҳеҷ пакете насб намешавад |

**Қадамҳо дар Railway:**
1. `New Project` → `Deploy from GitHub repo` → `killertjk59-maker/Akelcargo-site`.
2. Railway `railway.json`-ро худкарор хонда мегирад (NIXPACKS + `node server.js`).
3. `Settings → Networking → Generate Domain` — домени озодро гиред.
4. Тайёр! `/health` барои санҷиши саломтатӣ (200 `ok`).

> **Note:** Railway худаш `PORT`-ро медиҳад; `server.js` ба `0.0.0.0:$PORT` гӯш мекунад.
> Ҳеҷ гуна environment variable ё build command лозим нест.

### Дар компютери худ

```bash
# Node >= 18
node server.js            # http://localhost:8080

# ё бо порти дилхоҳ
PORT=3000 node server.js

# ё ҳамчун файли содда (бе сервер)
# index.html-ро дар браузер кушоед
```

## Функсияҳо

| Соҳа | Чӣ тавр кор мекунад |
|---|---|
| **Каталог** | 8 категория, 43 маҳсулот, менюи пурра (бургер) дар header |
| **Ҷустуҷӯ** | Пешниҳоди зинда (маҳсулот + категория), таърихи ҷустуҷӯ, ҳарфҳои гарм |
| **Филтрҳо** | Категория, бренд, нарх (2 майдон + слайдер), рейтинг, танҳо бо тамос, танҳо мавҷуд |
| **Тартибдодан** | 7 усул: машҳуртарин, нарх ↑↓, рейтинг, шарҳҳо, тамос, навтарин |
| **Намуди намоиш** | Шабақ / рӯйхат, «бештар нишон деҳ» |
| **Саҳифаи маҳсулот** | Галерея, интихоби вариант (ранг/андоза), миқдор, табҳо: тавсиф · хусусият · шарҳҳо |
| **Шарҳҳо** | Баҳои умумӣ + ҷадвали 5 ситора, шарҳҳо бо аксҳо, «Шарҳ нависед» (модалӣ) |
| **Сабад** | Drawer, миқдор ±, ҳазф, коди тахфиф, прогресси ирсоли ройгон |
| **Кодҳои тахфиф** | `OSHXONA10` (10%), `OSHXONA500` (500 смн.), `NEW2026` (15%) |
| **Чек-аут** | 3 қадам: ирсол → пардохт → тасдиқ, бо санҷиши маълумот |
| **Фармоишҳо** | Рӯйхат, таймлайни 4 қадамӣ, пажгирӣ, «симулятсияи қадами навбатӣ» |
| **Огоҳномаҳо** | Занг бо баджи ҳисобкунак, 4 намуд (фармоиш/аксия/нарх/система), «ҳамаро хонда шуд» |
| **Дӯстдоштаҳо** | Саҳифаи алоҳида, «ҳамаро ба сабад» |
| **Муқоиса** | То 4 маҳсулот, пайи поён, ҷадвали муқоиса |
| **Тамоси рӯз** | Ҳисобгари вақт то шабонарӯзӣ + саҳифаи алоҳида |
| **Мавзӯъ** | Равшанӣ / торикӣ, дар localStorage захира мешавад |
| **Профил** | Кабинет, статистика, таҳрири маълумот, бонус |
| **Дигар** | Тосту (3–4 сонӣ), ҳолати холӣ, скелетон, breadcrumb, «Ба боло», FAB |

## Сохтмон

```
.
├── index.html        # сохтори саҳифа
├── server.js         # сервери статикии Node (барои Railway)
├── package.json      # танҳо script-и start
├── railway.json      # конфигурацияи Railway
├── css/styles.css    # дизайн-система (токенҳо, компонентҳо, адаптивӣ)
└── js/
    ├── icons.js      # SVG-иконкаҳо ва расмҳои маҳсулот (бе эмодзи)
    ├── data.js       # маҳсулот, категория, баннер, кодҳои тахфиф
    └── app.js        # ҳолат, роутер (hash), рендер, ҳодисаҳо
```

Ҳама чиз дар браузер кор мекунад: `localStorage`-ро барои сабад, дӯстдоштаҳо,
фармоишҳо, огоҳномаҳо, мавзӯъ ва таърихи ҷустуҷӯ истифода мебарад.
Бе backend, бе node_modules, бе талаботи шабакавӣ (ғайр аз Google Fonts).
